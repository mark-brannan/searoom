# Visual identity — card-sized note

**Name.** *Searoom*: room to maneuver — what the rules exist to protect.
One word, lowercase in code (`searoom`), capitalized in prose (Searoom).

**Positioning line.** "See the rules of the road."

**Palette direction.** Night-sea darks as the ground — this is a
night-lights app first, so dark is the subject, not a theme option.
Ink-blue-black field (not pure black except in the bearing view, which is
lights-on-black by definition). The accent system is the three light
colours of Rule 21, used exactly:

- red `#ff3b30`-family — port, warnings, "not under command"
- green `#34c759`-family — starboard, correct answers
- white `#f5f5f0`-family — masthead/stern, primary text

Yellow (towing light) exists in the data and may appear in scenes, but is
not an interface accent. Tune exact values to WCAG AA on the dark ground.

**Feel.** Warm and salty, not corporate; calm night watch, not arcade.
Typography quiet and legible; the glowing lights are the only spectacle.
